Workflows

Exporting AI as a PDF

  1. File > Save As
  2. Select Adobe PDF (*.PDF) as the format
  3. Choose a location, name your file, and click Save
  4. In the Save Adobe PDF dialog, select the preset "High Quality Print"
  5. Click Save PDF

Exporting Assets with Asset Export

  1. Select artwork to be exported
  2. Drag the slected artwork into the Asset Export Panel
  3. Choose desired format
  4. Select the export scale and resolution
  5. Click Export
  6. Choose a location to save it and click select

Setting Layer to Not Print

  1. Open Layers panel
  2. Double-click layer that you want to not print to open Layer Options
  3. In Layer Options, uncheck Print
  4. Click OK

Setting Up a Layout Grid

  1. Create a rectangle that is the size of your artboard
  2. Select rectangle and go to Object > Path > Split into grids
  3. Set the number of rows, columns, and your gutter size
    • Even numbers recommended.
  4. Click Ok

Design Donts

Box Design

What is it?

Wrapping every piece of content — headlines , paragraphs, images — in its own bordered or filled container, so the boxes do the work of organizing the page instead of space, proximity, hierarchy, and contrast doing it.

Ways to Avoid:

  • Before adding a box or container with a fill and/or stroke, ask yourself: "what is this doing that space couldn't?"
  • Limit yourself to one container per composition, spent only where it's earned
  • Use proximity, alignment, contrast, and space to group and separate content instead
  • Don't default to a box just because a template or app convention uses one

Overtly Center Alignment

What is it?

Centering every element by default instead of choosing alignment intentionally — text, images, and headers all centered regardless of relationship, so nothing shares an edge and the eye has no consistent line to follow.

Ways to Avoid:

  • Set up margin/grid guides before placing content
  • Reserve true centering for genuine symmetry
